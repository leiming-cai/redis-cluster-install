完整替换文件内容：

```dockerfile
# E2E node fixture — one Redis Cluster node with a real sshd + systemd.
#
# Base is the official redis:8 image (currently 8.10.2, Debian 13 trixie) so
# that cluster-config.sh's full 9-step deployment is validated against the
# target Redis version. It previously used ubuntu:22.04 + apt redis-server,
# which meant Redis 8 was never exercised despite being the shipped target.
#
# The image ships no gosu and no su-exec, so "let the entrypoint drop
# privileges" is not available — ENTRYPOINT [] plus --user redis is the only
# way to control the uid. That matters here: with the entrypoint in place,
# systemd could start as the redis user and systemctl would break entirely.
#
# Docker Hub is unreachable from this host; REGISTRY is overridable so a dead
# mirror costs one environment variable instead of a source edit.
ARG REGISTRY=docker.m.daocloud.io/library
FROM ${REGISTRY}/redis:8

ENV DEBIAN_FRONTEND=noninteractive

# policy-rc.d must exist BEFORE apt runs: dpkg tries to start services when it
# installs systemd, and there is no init in the build container. Without it
# the build emits "invoke-rc.d: could not determine current runlevel" and
# tries to launch units that cannot work.
RUN printf '#!/bin/sh\nexit 101\n' > /usr/sbin/policy-rc.d \
 && chmod +x /usr/sbin/policy-rc.d \
 && apt-get update -qq \
 && apt-get install -y -qq --no-install-recommends \
        openssh-server systemd systemd-sysv sudo procps iproute2 \
 && rm -rf /var/lib/apt/lists/* \
 && rm -f /usr/sbin/policy-rc.d

ENTRYPOINT []

# Root password + password auth: the whole deployment runs over sshpass.
RUN echo 'root:TestPw123!' | chpasswd && \
    mkdir -p /var/run/sshd && \
    sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config && \
    sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/' /etc/ssh/sshd_config

RUN echo '* soft nofile 65535' >> /etc/security/limits.conf && \
    echo '* hard nofile 65535' >> /etc/security/limits.conf

VOLUME ["/sys/fs/cgroup"]
CMD ["/sbin/init"]
```

> **不要保留** `build-essential gcc g++ make tar curl ca-certificates`：
> 不再编译 Redis。也不要保留 apt 的 `redis-tools`：base 自带且版本与节点一致。

- [ ] **Step 2: 替换 provision()**

结束的 `}`）整体替换为：

```bash
provision() {
    local host="$1" out rc=0
    # Quoted heredoc: nothing is expanded locally, so the remote script needs
    # no \$ escaping and PREFIX travels as a positional argument the same way
    # every other remote script in cluster-config.sh receives its parameters.
    out="$(ssh_root "$host" bash -s "$PREFIX" 2>&1 <<'PRE'
set -e
PREFIX="$1"
mkdir -p "$PREFIX/bin" "$PREFIX/cluster" "$PREFIX/log" \
         /etc/redis/cluster /var/lib/redis/cluster /var/run/redis/cluster

# Recreate the shape apt's redis-server package leaves behind: /etc/redis is
# 0770 redis:redis WITH the setgid bit. That is exactly why create_dirs must
# chown the PARENT trees and not just the cluster subdirectory (commit
# 2eb4aee) -- a redis user recreated with a new uid cannot traverse a 0770
# parent, so every file below it is unreachable no matter how correctly it is
# owned itself.
#
# The redis:8 image has no /etc/redis at all, so this precondition does NOT
# appear by itself. Without these two lines the E2E would silently stop
# reproducing the very defect this fixture exists to guard.
install -d -o redis -g redis -m 0770 /etc/redis
chmod g+s /etc/redis

# The image ships binaries in /usr/local/bin; cluster-config.sh expects them
# under $PREFIX/bin. Symlink rather than copy: one inode, and preflight's
# `-x` test follows the link.
ln -sf /usr/local/bin/redis-server "$PREFIX/bin/redis-server"
ln -sf /usr/local/bin/redis-cli    "$PREFIX/bin/redis-cli"

id redis >/dev/null 2>&1 || useradd -r -s /usr/sbin/nologin redis

# Assert the three preconditions cluster-config.sh's preflight checks, so a
# provisioning failure surfaces HERE instead of three steps later as a
# preflight error that reads like a cluster-config.sh bug.
[ -x "$PREFIX/bin/redis-server" ] || { echo "provision: redis-server binary missing" >&2; exit 1; }
[ -x "$PREFIX/bin/redis-cli" ]    || { echo "provision: redis-cli binary missing" >&2; exit 1; }
id redis >/dev/null 2>&1          || { echo "provision: redis user missing" >&2; exit 1; }
PRE
    )" || rc=$?
    if [ "$rc" -ne 0 ]; then
        printf '%s\n' "$out" >&2
        fail "pre-provisioning $host failed (exit $rc)"
    fi
}
```

- [ ] **Step 1: 先证明旧判定是坏的（RED）**

在临时目录写一个探针，对**真实形态**的 `cluster nodes` 输出跑旧谓词：

```powershell

  && echo "OLD PREDICATE: PASSES on a DEAD master  <-- broken" \
  || echo "OLD PREDICATE: correctly rejects"
'@ | Set-Content "$env:TEMP\old-pred.sh" -Encoding utf8

@'
victim="aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
replica="bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb"
victim_line="$victim 172.19.0.2:6379@16379 master,fail - 0 0 2 disconnected"
```

- [ ] **Step 2: 替换 DoD5 段**

把 `scripts/e2e-cluster-config.sh` 从 `log "DoD5: kill a master, expect promotion"`
到该段 `echo "  promotion OK"` 整体替换为：

```bash
log "DoD5: kill a master, expect its replica to be promoted"
# `cluster nodes` fields:
#   $1 id   $2 ip:port@cport[,hostname]   $3 flags   $4 master-id   ...
# Field 4 is the master id (all zeros on a master), so `$4==V` uniquely
# identifies V's replica. That lookup MUST happen before the kill -- the
# replica is the object we are going to watch.
#
# The previous version polled for `$1==V && $3 ~ /master`, which cannot detect
# anything: V is already a master before it is killed, and once it dies its
# line merely gains a `fail` flag, so `$3` still contains "master". The
# condition was true the instant `systemctl stop` returned. It was green for
# entirely the wrong reason. Polling the replica's flags is the check that
# means what it claims to mean.
#
# index(), not a regex: the dots in an IP would otherwise be wildcards.
nodes_of() {
    ssh_root "$A_IP" "$PREFIX/bin/redis-cli -a $PASS --no-auth-warning \
              -h $A_IP -p 6380 cluster nodes"
}

victim_id="$(nodes_of | awk -v a="$A_IP:6379@" 'index($2, a) {print $1; exit}')"
[ -n "$victim_id" ] || fail "could not find the victim's node id"
replica_id="$(nodes_of | awk -v v="$victim_id" '$4==v {print $1; exit}')"
[ -n "$replica_id" ] || fail "no node reports master id $victim_id"
echo "  victim node id=$victim_id  replica node id=$replica_id"

ssh_root "$A_IP" "systemctl stop redis-6379"
promoted=0
for _ in $(seq 1 12); do
    sleep 5
    if nodes_of | awk -v r="$replica_id" '$1==r && $3 !~ /(slave|replica)/ {found=1} END{exit !found}'; then
        promoted=1
        break
    fi
done
[ "$promoted" -eq 1 ] || fail "replica $replica_id was not promoted within 60s"
echo "  promotion OK"
```
